Git

Comandos Essenciais

Controle de versão distribuído para desenvolvedores Prof.: Diego Ramos Inácio

O que é Git? 🤔

  • Sistema de controle de versão distribuído
  • Criado por Linus Torvalds em 2005
  • Rastreia mudanças nos arquivos
  • Permite colaboração em equipe
  • Mantém histórico completo do projeto
  • Funciona offline

Configuração Inicial ⚙️

git config --global user.name "Seu Nome"
Define seu nome para commits
git config --global user.email "seu@email.com"
Define seu email para commits
git config --list
Mostra todas as configurações

Iniciando um Repositório 🚀

git init
Inicializa um novo repositório Git na pasta atual
git clone <url>
Clona um repositório remoto para sua máquina
git status
Mostra o estado atual do repositório

Comandos Básicos 📝

git add <arquivo>
Adiciona arquivo específico à área de stage
git add .
Adiciona todos os arquivos modificados à área de stage
git commit -m "mensagem"
Confirma as mudanças com uma mensagem descritiva

Fluxo de Trabalho Git 🔄

Working Directory

Arquivos modificados

→

Staging Area

git add

→

Repository

git commit

Working Directory → git add → Staging → git commit → Repository

Visualizando Histórico 📊

git log
Mostra histórico completo de commits
git log --oneline
Histórico resumido em uma linha por commit
git log --graph
Mostra histórico com representação gráfica
git show <commit>
Mostra detalhes de um commit específico

Trabalhando com Branches 🌳

git branch
Lista todas as branches locais
git branch <nome>
Cria uma nova branch
git checkout <branch>
Muda para uma branch específica
git checkout -b <nome>
Cria e muda para uma nova branch

Merge e Conflitos 🤝

git merge <branch>
Faz merge de uma branch na branch atual
git diff
Mostra diferenças entre arquivos
git mergetool
Abre ferramenta para resolver conflitos

Conflitos acontecem quando duas branches modificam as mesmas linhas

Repositórios Remotos 🌐

git remote add origin <url>
Adiciona um repositório remoto
git push origin main
Envia commits para o repositório remoto
git pull origin main
Baixa e faz merge das mudanças remotas
git fetch
Baixa mudanças sem fazer merge

Comandos Úteis 🛠️

git reset --soft HEAD~1
Desfaz último commit mantendo mudanças
git reset --hard HEAD~1
Desfaz último commit e mudanças
git stash
Salva mudanças temporariamente
git stash pop
Restaura mudanças salvas no stash

.gitignore 🚫

Arquivo que especifica quais arquivos o Git deve ignorar:

# Comentários
*.log
Ignora todos os arquivos .log
node_modules/
Ignora a pasta node_modules
.env
Ignora arquivo de configuração
*.tmp
Ignora arquivos temporários

Boas Práticas ✨

  • Faça commits frequentes e pequenos
  • Use mensagens descritivas nos commits
  • Crie branches para novas features
  • Sempre teste antes de fazer push
  • Use .gitignore para arquivos desnecessários
  • Faça pull antes de push
  • Resolva conflitos cuidadosamente
